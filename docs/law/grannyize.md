# Grannyize, with hidden GeekFeatures

LOCKED 2026-10-28 — Barticus "gsi". KSD-wide credo (not kfiles-only).

The surface is Grannyized. The depth is never removed — it is hidden.

- GRANNYIZE THE SURFACE. The face a guest sees is plain words, few choices,
  Grannyable verbs (Open, Play, navigate). Jargon — zip/tar/install/sudo —
  never reaches the face. If Granny can't say what a button does, the button
  is wrong.
- HIDE THE GEEKFEATURES. Power is never deleted, it is buried. Owner-only depth
  (Move/Copy/Rename/Delete/Compress/Extract/Install/Edit, the kernel/brig
  machinery of #48) sits behind the Granny surface — an owner "More…" layer, a
  long-press, a mode — never in Granny's primary walk. Built for "the crazies
  who love to go deep on the system" and the distro boys & girls.
- NOTHING SITS AS A RAW FILE. Every type has a place and a primary Grannyable
  action; the geek path is the exception, never the default.

Scope: #45 Smart Tools (guest = Open/Play; owner CRUD + advanced hidden), every
app's drawer, #48 (the system stays pure and simple on top; the kernel/brig
fallback is a hidden mechanism, never a user-facing matrix).
